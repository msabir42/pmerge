Merge-insertion sort using linked lists. This is not an optimized implementation, but more like a Python exercise. As students at 42 School, we were exposed to this algorithm in the C++ modules, where we were forced to use containers as data structures (I used vectors and deques).

I know that those data structures will perform better than linked lists, especially when it comes to random access, but I wanted to rewrite it using linked lists anyway, just to see how the algorithm behaves with a completely different data structure and to better understand what is happening under the hood.
